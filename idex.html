GitHub Pages Deployment Guide

Host this website for free at <username>.github.io

  1. 1
    Create a new GitHub Repository Log into GitHub.com, click New, and name it joemar-retardo.github.io (or any repository name).
  2. 2
    Add `index.html` In your repository, click Add file > Create new file. Name the file index.html, paste the code of this file inside, and commit changes.
  3. 3
    Enable GitHub Pages Go to Settings > Pages in your repository. Under Build and deployment, set Source to Deploy from a branch, select main branch and /(root) folder, then click Save.
  4. 4
    Site Published! Your portfolio will be live in 1-2 minutes at https://<username>.github.io/.
